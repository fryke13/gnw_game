Update – 3. November 2026: I've added a version for the Anbernic RG SP. It's a FrontEnd for BaseOS. So you can use a 4GB (or larger, but not necessary) SD card, flash BaseOS onto it, then add the System folder from this zip file. Putting this into your Anbernic RG SP will have it boot straight into the game. Closing the lid puts it to sleep, and after a minute, it shuts down. Shutting down saves the state, and starting the device up again loads the state. The device remembers brightness (Select+VolumeControl) and volume settings through shutdowns as well. -> Edit: The RG SP version also works on the Anbernic RG-34XX, and I'm suspecting it'd also work on the RG-34XX SP. It expects a 720*480 pixel display, so probably won't work on RG-35XX SP etc.

October 2026: I just missed having any version of that 1980s Super Mario Bros. Game & Watch game on a device with a backlight. So I told an AI to basically create one for me. Took a few iterations (about 35) until I had a working game that felt good for short, chill breaks. Then had AI add a version for GBA and one for android. 28 builds later now, as of editing this: Now I can run the GBA version of a game that's at least somewhat similar to what I remember (although I've left some things out intentionally, while doing other things that werent' there before) on real GBA hardware or some emulation handheld, and use the android version on an android gaming handheld. No real plans to make it anything more as of now. But we've got 5 "worlds" of 7 levels, with difficulty increasing gradually. It's defintely beatable. And with a pause button (which Game & Watch games just didn't have in the 1980s), it's just plain better than starting a doomscroll if you have five minutes.
