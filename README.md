I just missed having any version of that 1980s Super Mario Bros. Game & Watch game on a device with a backlight. So I told an AI to basically create one for me. Took a few iterations (about 35) until I had a working game that felt good for short, chill breaks. Then had AI add a version for GBA and one for android. 28 builds later now, as of editing this: Now I can run the GBA version of a game that's at least somewhat similar to what I remember (although I've left some things out intentionally, while doing other things that werent' there before) on real GBA hardware or some emulation handheld, and use the android version on an android gaming handheld. No real plans to make it anything more as of now. But we've got 5 "worlds" of 7 levels, with difficulty increasing gradually. It's defintely beatable. And with a pause button (which Game & Watch games just didn't have in the 1980s), it's just plain better than starting a doomscroll if you have five minutes.
